# Extract Method for an Object of Class `metadynmeta`

Extract Method for an Object of Class `metadynmeta`

## Usage

``` r
# S3 method for class 'metadynmeta'
extract(object, what = NULL)
```

## Arguments

- object:

  an object of class `metadynmeta`.

- what:

  Character string. What specific matrix to extract. If `what = NULL`,
  extract all available matrices.

## Value

Returns a list of estimates.
